设备还没连接 Wi-Fi？可以先通过 USB 完成配置。

连接时，请在浏览器弹窗中选择 USB JTAG/serial debug unit。
01

Wi-Fi 网络

选择 2.4 GHz 网络，设备会在保存后尝试连接。

支持手动填写隐藏网络，最多 32 字节。
02

对话服务

OpenAI 兼容接口的 Base URL 和 API Key，例如 DeepSeek、OpenAI。

只支持 http:// 或 https://。设备会在后面拼接 /chat/completions。
设备连上 Wi-Fi 后，会用这里的 Base URL 和 API Key 获取模型列表，并默认选中第一个推荐模型。
03

语音服务

语音识别和语音合成。对话服务没有语音接口（如 DeepSeek）时，填写另一家服务，例如硅基流动或 OpenAI。

设备会在后面拼接 /audio/transcriptions 和 /audio/speech。留空时语音也使用对话服务的地址和 API Key。
可从常用音色中选择，也可以填写服务支持的其他音色。
填写后会自动获取语音服务的模型。
保存到设备

已保存的密码与 API Key 不会回显；留空会保留原值。
