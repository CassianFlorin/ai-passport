# 电脑 USB 配置

个人首页应用通过现有的 USB Serial/JTAG 连接接收 Wi-Fi 和 AI 服务配置。配置网页在电脑上
运行，设备可以在尚未连接 Wi-Fi 时完成设置。页面资源全部随项目提供，不依赖云端配置服务，
也不需要手机。

## 打开配置页面

准备 Python 3，以及支持 Web Serial 的桌面浏览器，例如 Chrome 或 Edge：

```bash
python3 tools/usb_config.py
```

打开命令输出的本地地址，通常是 `http://127.0.0.1:8765/`。可以使用 `--port` 指定其他端口，
或者用 `--open` 打开默认浏览器。不支持的浏览器会提示改用兼容的桌面浏览器。

1. 开启设备电源，用可传输数据的 USB 线连接电脑。
2. 关闭占用设备端口的串口监视器、烧录程序及其他应用。
3. 点击连接按钮，在弹窗中选择 USB JTAG/serial debug unit。
4. 读取当前配置，填写 2.4 GHz Wi-Fi 名称和密码，也可以填写 AI 服务接口地址及设备令牌。
5. 保存。页面分别显示保存结果和 Wi-Fi 连接、获取 IP 的结果，网络状态会自动刷新。
6. 使用串口监视器或烧录工具前，先在页面中断开连接。

浏览器连接用于读写设置，不会烧录固件。不支持该 USB 协议的固件会超时，页面会提示更新。
打开网页本身不会打开串口，用户选择设备后才建立会话。设备保留已有的独立个人首页与三键操作。

## 设备上的对话入口

在个人首页双击 OK 打开功能列表。第一项为 AI 对话，后面依次为系统状态和设置。
UP/DOWN 每次移动一项，到两端后不循环；单击 OK 进入，长按 OK 返回列表。
返回时保留此前选中的项目。

对话页显示实时 Wi-Fi 状态，以及是否已经保存服务地址。连接状态快照只包含公开标志，
没有网络名称、服务地址或凭证。USB 工作任务处理设置和网络事件后发布快照；
界面读取快照时，不会在持有 LVGL 锁期间进行 Flash 或无线操作。

服务地址只显示为已保存，不显示为连接或认证成功。页面明确提示对话尚未接入、
暂不能开始录音。对于配置缺失、连接重试、存储错误以及 USB/Wi-Fi 不可用，
页面会给出对应的 USB 配置指引。此页面的按键不录音、不发送请求，也不更改声音设置。
真正的语音对话仍需要实现服务协议，并单独验证音频和网络行为。

## 配置项和限制

| 配置项 | 限制与行为 |
| --- | --- |
| Wi-Fi 名称 | 最多 32 个 UTF-8 字节；可以手动填写或从扫描结果选择 |
| Wi-Fi 密码 | 开放网络为空，否则为 8–63 个 UTF-8 字节，或 64 位十六进制密钥 |
| 服务接口地址 | 最多 384 个 ASCII 字节；支持 `http://`、`https://`、`ws://`、`wss://`；不接受地址内的用户名、密码或片段 |
| 服务令牌 | 最多 512 个 UTF-8 字节 |

密码和令牌只允许写入。读取配置时仅返回是否已经保存，不会返回原文。密码或令牌留空表示
保留原值；勾选对应的清除选项才会删除。更换 Wi-Fi 名称后，需要重新填写密码，或明确选择开放网络。

Wi-Fi 名称为空并明确清除密码时，会停用 Wi-Fi 连接。仅修改服务地址不会重新连接未改变的
Wi-Fi。设备正在连接网络时可能暂时无法扫描，此时仍然可以手动填写网络名称。

服务地址和令牌为后续 AI 客户端预留。本轮功能没有实现 AI 对话、协商服务协议、向目标服务
验证令牌，也不能证明设备能够访问互联网。获取 IP 只代表设备已经连接到路由器。

## 保存和恢复

应用把配置保存为 NVS 命名空间 `connection` 下的单个版本化数据项 `values_v1`，与声音设置
分开。存储操作成功后才更新运行中的配置。没有记录时使用默认值；记录损坏或版本不支持时
返回错误，不会静默擦除。用户明确保存后可以替换这类记录。

开机时使用已保存的 Wi-Fi 配置自动连接。断线后逐步增加重试间隔，最长为 30 秒，网页也提供
手动重新连接按钮。存储、Wi-Fi 和扫描操作都在 USB 工作任务中执行，不占用按键回调或 LVGL
任务。未配置网络时，无线功能只在扫描或应用网络配置时启动。

本功能不提供秘密信息加密。配置保存在设备现有的 NVS 分区中，不会执行整分区擦除，也不修改
分区布局。请勿发布 NVS 转储、设备配置或包含秘密信息的日志。

## 传输和验证

协议通过 `@PASSPORT1` 前缀标识版本。请求使用有长度上限的制表符分隔字段、十六进制 UTF-8
数据和换行结束符。响应使用相同前缀，携带 JSON 对象与请求 ID。秘密字段为 `*` 时保留原值，
为空时清除。客户端忽略没有协议前缀的控制台日志；设备遇到超长或混入二进制零字节的请求时，
丢弃至下一个换行，行缓冲区为 2304 字节。

静态检查会测试实际 C 解析器，对版本化存储注入故障，让网页客户端与 C 串口模拟端通信，
并验证本地服务器只开放随附页面资源。网页客户端的主机测试需要 Node.js 20 或更高版本，
运行页面服务只需要 Python 3。

```bash
./tools/validate.sh --static
./tools/validate.sh
```

真机验收仍需使用已经验证的固件，并取得明确的烧录许可。需要检查 USB 授权、反复连接和断开、
Wi-Fi 扫描、错误密码恢复、成功获取 IP、重启后的配置保留、密码与令牌的保留和清除，以及首页、
按键、音频同时工作的表现。AI 客户端协议实现后，还需要单独验证真实服务。
